## Descriptive Title

XPC services for iOS and iPadOS

## Request Type

Interoperability Request

## Description

Apple frameworks, such as the Watch Connectivity framework, are able to use XPC Services on iOS to facilitate both cross process communication and sandboxing of sensitive information. We request that the same XPC APIs that are available to these frameworks (and available to third parties on macOS) be made available on iPadOS and iOS. We also request that, when XPC events are triggered, iOS/iPadOS allocate execution time to the receiving application to handle the callback.
