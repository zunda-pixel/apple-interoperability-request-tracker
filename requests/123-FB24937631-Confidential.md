## Descriptive Title

Custom appearance for payment cards in Apple Wallet

## Request Type

Interoperability Request

## Description

Request for an iOS interoperability mechanism allowing users to customize the visual appearance of payment cards displayed in Apple Wallet, without providing third-party applications access to payment credentials or transaction data.
