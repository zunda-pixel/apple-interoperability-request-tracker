## Descriptive Title

iOS Critical Alert Entitlement and User Notifications framework capabilities

## Request Type

Interoperability Request

## Feature Requested

iOS Critical Alert Entitlement (com.apple.developer.usernotifications.critical-alerts) and associated User Notifications framework capabilities.

## Description

We are requesting interoperability with the Critical Alert API to ensure emergency incident management notifications can bypass Do Not Disturb and Silent modes for safety-critical infrastructure monitoring.
