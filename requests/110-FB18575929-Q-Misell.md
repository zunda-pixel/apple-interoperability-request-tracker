## Descriptive Title

FIDO in Wallet - Interopability

## Request Type

Interoperability Request

## Feature Requested

FIDO in Wallet

## Reason for Request

It is evident that Apple Wallet supports FIDO tokens in Wallet Passes, see here: <https://woof.tech/@unlobito/112938135668265163>

However, this operating system feature is not documented, nor available to developers under terms compatible with the DMA.

I am therefore requesting Apple make this feature widely available, in compliance with the DMA.

## Product Description

We work with European Railways on their train ticket issuing system.

## How the Feature Will Be Used

Use of this will help us protect these tickets against copying.

## Where Offered

European Union

## Evaluation of Alternatives

Yes, nothing else seems to offer the same solution.

## Confidentiality

Fully available to other developers
