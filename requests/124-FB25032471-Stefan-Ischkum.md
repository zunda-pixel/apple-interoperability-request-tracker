## Descriptive Title

AirDrop

## Request Type

Interoperability Request

## Feature Requested

Native AirDrop interoperability for a third-party operating system (CarbyneOS) without an iOS companion app

## Description

CarbyneOS (a third-party, AOSP-derived mobile operating system without Google Mobile Services, developed by Smahoma e.U., Austria) requests Article 6(7) DMA interoperability with Apple’s native AirDrop: the AirDrop protocol specification and the high-bandwidth peer-to-peer Wi-Fi (AWDL-class) transport information needed for a CarbyneOS device to send files to, and receive files from, Apple devices through the native AirDrop UI, with no CarbyneOS app installed on the Apple device. The CarbyneOS side is a system-integrated implementation; Apple-side user consent remains authoritative; the implementation is clean-room (no GPLv3, no copied Apple/Google code). This is distinct from the company’s separate “Carbyne Share” protocol and is not an iOS companion app.
