## Descriptive Title

Dual SIM cellular line selection, preferred cellular line for contacts, and cellular line information for call history

## Request Type

Interoperability Request

## Feature Requested

Dual SIM cellular line selection, preferred cellular line for contacts, and cellular line information for call history

## Description

Request for improved Dual SIM interoperability between iOS and third-party contact management and Default Dialer applications.

The requested interoperability would allow eligible applications to work consistently with the Dual SIM information already managed by iOS, particularly in three areas:

1. Access to the user-defined Cellular Plan Label for each available cellular service, such as “Personal” or “Business”.
2. A supported mechanism to read and update the preferred cellular line associated with a contact, allowing third-party contact applications and Apple’s Contacts/Phone experience to use the same preference.
3. Access to an opaque identifier for the cellular service associated with a call-history conversation, where available, so applications can determine which cellular line was associated with an incoming or outgoing call.

The objective is to allow a consistent Dual SIM experience across iOS Contacts, Phone, Default Dialer applications and call history without requiring access to sensitive subscription information.

The requested functionality does not require ICCID, IMSI, subscription credentials or other sensitive SIM identifiers. An opaque cellular-service identifier, together with the user-visible plan label, would be sufficient.
