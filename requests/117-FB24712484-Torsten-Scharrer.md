## Descriptive Title

Allow default dialer apps to identify the cellular service receiving an incoming carrier call

## Request Type

Interoperability Request

## Feature Requested

Allow default dialer apps to identify the cellular service receiving an incoming carrier call

## Description

A default dialer can enumerate cellular services and select one for an outgoing carrier call, but cannot determine which cellular service receives an incoming carrier call. We request a privacy-preserving API exposing the receiving CellularService.id to the user-selected default dialer and a system-controlled way to present the user’s line label prominently.
