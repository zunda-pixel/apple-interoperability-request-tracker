## Descriptive Title

Screen Time, FamilyActivityPicker

Interoperability Request

## Feature Requested

Screen Time, FamilyActivityPicker

## Description

My name is Frederik Riedel and I’m the developer behind an app called “one sec.” With one sec, we help millions of users around the world to save more than 1000+ years from scrolling social media every single week. We help grown-up adult users to limit their own screen time (not adolescents who are managed by their parents). For this, we make use of Apple’s FamilyActivityPicker, which is offered through the FamilyControls framework.

Apple themselves use a different or slightly modified version of the FamilyActivityPicker which offers higher stability and a greater feature set in their native iOS Screen Time Settings. Especially when a realistic number of apps is installed on the user’s device, the FamilyActivityPicker for 3rd party apps crashes reproducibly, while Apple’s own picker in Screen Time settings works without issues (for example, trying to expand the “Other” category).

On top of keeping the more stable version for themselves, Apple is able to:

* **Change the title of the picker:** The FamilyActivityPicker in 3rd party apps always says “Choose Activities” while Apple can change the title to “Choose Apps.” It would be great if developers could freely choose the title or remove it entirely.
* **Change the search bar position:** The FamilyActivityPicker always has search inline, which can be tricky because users have to pull down the list to reveal search. It would be preferable if the developer could decide about the positioning of the search bar.
* **Change NavigationBarItems:** Apple’s native picker includes a “Next” button in the top right corner. The FamilyActivityPicker does not offer such modifications.

It would be amazing if Apple would make these capabilities available to 3rd party apps as well.
