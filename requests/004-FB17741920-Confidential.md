## Descriptive Title

Wearable and accessory ecosystem parity with Apple Watch and AirDrop

## Request Type

Interoperability Request

## Description

As a family wearable smart device enterprise serving hundreds of millions of users, the requestor includes various forms of device categories, such as smart watches, smart bracelets, smart scales, smart treadmills, smart headphones, and smart hearing aids.

The requestor hopes to achieve the same user experience as Apple Watch, AirDrop, and similar features in the Apple ecosystem, so that users can better enjoy the services and experiences within Apple’s ecosystem.
