## Descriptive Title

User-selectable default voice assistant in the EU (side button, “Hey Siri”-equivalent activation and CarPlay voice button), as already offered in Japan

## Request Type

Interoperability Request

## Feature Requested

System default voice-assistant activation (iPhone side button press-and-hold and CarPlay vehicle voice button)

## Reason for Request

On iOS in the EU, the system voice-assistant activation points (press-and-hold of the side button, and the vehicle voice button in CarPlay) are reserved for Siri. Users cannot choose another voice app as the default. Apple already provides this choice in Japan (iOS 26.2 and later, App Intents assistant schema with the com.apple.developer.side-button-access.allow entitlement), which shows it is technically feasible.

Article 6(3) DMA requires the gatekeeper to allow and technically enable end users to easily change default settings on the operating system and virtual assistant that steer users to the gatekeeper’s own services. Article 6(7) DMA requires free and effective interoperability with the same hardware and software features controlled via iOS as are available to Apple’s own services (here, Siri’s exclusive access to these activation points).

We request that Apple make the Japan side-button assistant option available in the EU, and extend the same user choice to the CarPlay vehicle voice button, so that a user can pick a third-party voice app (such as SuomiNavi+ for driving) as the default.

## Product Description

SuomiNavi+ is an iOS navigation app by Rolf Laine (Apple Developer Team ID K58D53H77S), developed in Finland and currently in TestFlight testing ahead of App Store release. It holds the CarPlay Navigation entitlement and has an in-app voice assistant (“Tekoäly”) for route planning and navigation by voice.

## How the Feature Will Be Used

If the user selects SuomiNavi+ as the default voice app, a press-and-hold of the side button, or a press of the CarPlay vehicle voice button, opens SuomiNavi+’s voice assistant directly and it starts listening (as described in Apple’s Japan documentation: the app starts an audio session immediately). The user can change the setting back to Siri at any time. Main use: drivers controlling navigation by voice without first going through Siri.

## Where Offered

European Union

## Evaluation of Alternatives

* **App Intents / App Shortcuts / SiriKit:** require invoking Siri first and saying the app name.
* **Action Button with an App Shortcut:** available only on some iPhone models, not reachable in CarPlay, and not a default-assistant setting.
* **Japan side-button assistant schema:** exactly the needed mechanism, but restricted by Apple to Japan (region and physical location) and to the iPhone side button.
