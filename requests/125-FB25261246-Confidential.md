## Descriptive Title

Per-app network connection controls for digital-wellbeing apps

## Request Type

Interoperability Request

## Description

Request for user-authorized interoperability with iOS network connection controls to enable digital-wellbeing applications to temporarily restrict network connectivity for user-selected applications while maintaining connectivity for other applications.
